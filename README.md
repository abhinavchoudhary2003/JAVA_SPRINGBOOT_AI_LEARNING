## 🎯 Goals

- Build a strong foundation in **Core Java** (OOPs, Collections, Exception Handling, Multithreading, Generics)
- Get comfortable with **Advanced Java** (Servlets, JDBC, Web Applications)
- Practice by building small projects alongside theory

## 🗺️ Roadmap

Here's the learning path I'm following, step by step:

1. ✅ **Core Java** — OOPs, Collections, Exception Handling, Multithreading, Generics
2. ✅ **Advanced Java** — Servlets, JDBC, Web Applications
3. ⏳ **Spring Core** — IoC, Dependency Injection, Beans, ApplicationContext
4. ⏳ **Spring Boot** — Auto-configuration, REST APIs, Spring Data JPA
5. ⏳ **Microservices** — Service design, communication, API Gateway, Config Server, Eureka
6. ⏳ **Docker & Kafka** — Containerization and event-driven architecture
7. ⏳ **Spring AI** — Integrating AI/LLM capabilities into Spring applications
8. 🚀 **Projects** — Applying everything above into real-world, end-to-end projects

*(✅ = done, ⏳ = upcoming, 🚀 = ongoing/planned)*
